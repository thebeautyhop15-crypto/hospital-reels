# 병원 시술 안내 릴스 자동 제작

포스터 이미지와 기획서만 올리면 **AI 대본 초안 → 사람 검수 → 음성·자막을 입힌 9:16 릴스 영상**까지 GitHub에서 자동으로 만들어집니다.
사용하는 도구는 GitHub Actions, Gemini API 무료 등급, Edge TTS, FFmpeg이며 모두 무료입니다.

```
01_plan   (기획) /<주차>/brief.yml     ① 기획서 작성 → AI가 대본 초안 생성
02_script (구성) /<주차>/script.md     ② 대본 검수 → 상태를 '승인'으로 변경
03_design (디자인)/<주차>/*.jpg|png    ③ 포스터 이미지 업로드 (파일명 순서대로 나옴)
03_design/_common/                     로고·배경음악·글꼴 (선택)
04_output (출력) /<주차>/reel.mp4      ④ 완성 영상 (자막 reel.srt, 표지 cover.jpg 포함)
config/brand.yml                       병원 공통 설정 (처음 한 번만)
```
폴더 이름은 윈도우·맥 어디서나 깨지지 않도록 영문으로 했습니다.
주차는 ISO 주차 형식입니다. 예: 2026년 12월 7일이 있는 주 → `2026-W50`

---

## 처음 한 번만 할 일

1. **저장소 만들기**: GitHub에서 새 저장소를 **Public**으로 만들고 이 폴더 전체를 올립니다.
   (공개 저장소는 Actions 실행 시간이 무료입니다. 비공개로 하면 월 2,000분까지 무료입니다.)
2. **Gemini API 키 발급**: Google AI Studio(aistudio.google.com) → Get API key → 키 복사
   - 무료 등급에서는 입력 내용이 Google 제품 개선에 쓰일 수 있습니다. **환자 개인정보는 기획서에 절대 넣지 마세요.**
3. **키 등록**: 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - 이름 `GEMINI_API_KEY`, 값: 복사한 키
   - (선택) Variables 탭에서 `GEMINI_MODEL` 을 등록하면 모델을 바꿀 수 있습니다. 기본값은 `gemini-2.5-flash`
4. **Actions 쓰기 권한 확인**: Settings → Actions → General → Workflow permissions → **Read and write permissions** 선택
5. **병원 정보 입력**: `config/brand.yml` 의 병원명·연락처·색상·고지문을 수정합니다.

## 매주 할 일

| 순서 | 할 일 | 자동으로 일어나는 일 |
|---|---|---|
| ① | `01_plan/<주차>/brief.yml` 작성 후 올리기 | 몇 분 안에 `02_script/<주차>/script.md` 대본 초안이 생성됨 |
| ② | 대본 검수·수정 → 맨 위 `상태: 초안` 을 `상태: 승인` 으로, `검수자` 에 이름 입력 | — |
| ③ | `03_design/<주차>/` 에 포스터 이미지 올리기 | ②와 ③이 모두 끝나면 영상 제작이 시작됨 |
| ④ | `04_output/<주차>/reel.mp4` 확인 | 매주 월요일 08:47(한국 시간)에도 빠진 주차를 확인해 제작함 |

- 승인 후 대본·포스터·설정을 고치면 영상이 자동으로 다시 만들어집니다.
- 승인 전에 미리 보려면: Actions → "2. 릴스 영상 만들기" → Run workflow → 주차 입력 + "승인 전이라도 미리보기로 제작" 체크

## 대본 작성 규칙
- `# 나레이션` 아래의 `- ` 로 시작하는 줄만 사용됩니다. **한 줄이 자막 한 장면**입니다.
- 한 줄은 25자 이내를 권장합니다. 길면 자막이 두 줄로 나뉩니다.
- 대본 아래의 검수 체크리스트를 모두 확인한 뒤 승인하세요. 의료광고 사전심의 대상 여부는 별도로 확인해야 합니다.

## 영상 구성 (기본 약 25~35초)
1. 오프닝 2초: 병원명 + 시술명
2. 본문: 포스터 이미지가 천천히 확대·축소되고, 나레이션과 자막이 나옴 (포스터 여러 장이면 시간을 똑같이 나눔)
3. 엔딩 3초: 병원명·연락처·주소·고지문·심의번호

## 주의
- 공개 저장소는 60일 동안 활동이 없으면 정기 실행이 자동으로 꺼집니다. 정기 실행이 매주 `04_output/last_run.txt` 를 커밋해 이를 막도록 해 두었지만, 꺼졌다면 Actions 탭에서 다시 켜 주세요.
- 정기 실행 시각은 GitHub 사정에 따라 늦어질 수 있습니다.
- Edge TTS는 Microsoft의 무료 음성 서비스입니다. 서비스 쪽 사정으로 실패하면 Actions 로그에 오류가 남습니다. 이때는 다시 실행하세요.
- 배경음악·글꼴·로고는 상업적 이용이 허용된 파일만 사용하세요.
- 영상은 저장소에 쌓입니다(1편에 수 MB). 저장소 권장 용량은 1GB이므로, 1년쯤 지나면 오래된 영상을 정리하세요.

```bash
python build_reel.py 2026-W49 --force            # 실제 음성 포함
```
